# ML Week 2: Linear Regression

Practice copies of the Week 2 lab notebooks from Coventry University's
6001CMD Machine Learning module lab materials, as taught at PSB Academy
(module slides by Dr Dianabasi Nkantah). The originals, with their outputs, are kept in the
student's private course repo.

| Notebook | What it does | Needs |
| -------- | ------------ | ----- |
| `6001CMD_Week2_Q1` | Simple linear regression: restaurant profit from city population | `Rest_Pop_Profit.csv` |
| `6001CMD_Week2_Q2` | Multiple linear regression: house price from area and bedrooms | `House_Price_Data.csv` |
| `6001CMD_Week2_Q3` | Linear regression on a brain-weight dataset | `Brain_Weight_dataset.csv` |
| `6001CMD_Week2_Q4` | matplotlib scatter and line plots of weather data | nothing |
| `6001CMD_Week2_Q5` | matplotlib pie charts | nothing |
